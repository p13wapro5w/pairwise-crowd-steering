# pairwise-crowd-steering

人群在狭窄路口互相推挤、绕障碍走成锯齿、队伍被卡住不分散：避障用固定半径；邻居查询只查前方；速度按目标方向；路径跟随不考虑密度；局部避让和全局路径冲突；人群分组不区分队伍；楼梯和门洞用同一半径；转向角速度无限；掉队不重算路径；固定时间步和帧率绑定。game/crowd_steering.py 是核心，tests/test_crowd_steering.py 15个红。要修的是：动态半径；全向邻居；密度限速；路径重规划；局部全局融合；队伍分层；地形半径；转向限速；掉队恢复；固定步长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
